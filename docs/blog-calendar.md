# Blog content calendar (3 posts/day)

Goal: topical authority around home-service local SEO (roofing, plumbing, septic, HVAC),
low-competition long-tail keywords, and every post linking to a service page plus the free audit / book-a-call CTA.

**How to publish a day:** add `scripts/blog_data/day_YYYY_MM_DD.py` (copy the previous day's file; each post is a dict with
slug, cat, title, h1, desc, read, date, body, svc_*), then run `python3 scripts/build_blog.py`. It writes the posts, adds cards to
`blog.html` and the category page, and updates `sitemap.xml`. Always add 2–3 in-body links to older posts.
