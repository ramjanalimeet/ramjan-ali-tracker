# Blog calendar: 3 posts per day

Goal: topical authority in local SEO for home-service contractors (roofing, plumbing,
HVAC, septic), using low-competition long-tail topics, each linking to a service page
and ending in a free-audit / WhatsApp / Book-a-call CTA.

Services the posts sell: Local SEO by trade (`/local-seo/*`), Technical SEO, On-Page SEO,
Content SEO, Link Building, SEO Audits (`/seo-services/*`), city pages (`/locations/*`).

## How to publish a post

1. Add `scripts/blog_data/<slug>.py` (copy an existing one; fields are documented in `scripts/build_blog.py`).
2. Run `python3 scripts/build_blog.py` (page, blog index card, category card, sitemap).
3. Set `date` to the publish day. Commit and push.

Keep posts truthful: no invented statistics, no guaranteed rankings.
